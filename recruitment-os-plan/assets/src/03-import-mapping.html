What each number means

1

Two columns, one arrow. Left is exactly what the file said; right is the standard field it maps to. A recruiter reads it like a sentence.

2

It learns. Confirmed mappings are saved per person and per source, so the second upload of the same sheet is basically automatic.

3

Confidence chips. Green 85%+ auto-accepted, amber 60–85% asks to confirm, red is never guessed — the human decides.

4

Custom fields. Anything non-standard (e.g. “Visa status”) becomes a typed field the Team Lead controls — flexibility without breaking the universal model.

TL power: a Team Lead can lock which fields are required for their desk, so every recruiter's upload stays consistent.
Under the hood: a heuristic + embedding matcher proposes each source header to its canonical field; accepted mappings are stored as a reusable template keyed to the user and file signature.
